# Cozy Cup Café Website

Cozy Cup Café is a responsive and interactive café website designed to showcase popular food and drinks, special offers, menu prices, and café information. It also allows visitors to select menu items, calculate their total bill, and book a table online.

The website is developed using HTML, CSS, and JavaScript.

## Features

- Home section with café introduction and coffee image
- About Us section with Read More and Read Less functionality
- Popular menu items
- Special offers section
- Menu price list with category filtering (All, Drinks, Pastries)
- Interactive menu item selection
- Automatic total price calculation
- Table booking form
- Form validation
- Indoor and outdoor seating options
- Light/Dark mode toggle
- Student and senior citizen discount eligibility
- Café opening status based on current time
- Character counter for special instructions
- Interactive menu table hover effects
- Responsive design for mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open the live website using the link below.
2. Explore the Home, About Us, Menu, and Special Offers sections.
3. Use the menu filters to view drinks and pastries.
4. Select your favorite menu items to calculate the total price.
5. Switch between Light and Dark modes.
6. Fill out the table booking form with your details.
7. Explore the additional interactive JavaScript features.

To run the website locally, download or clone this repository and open `index.html` in your browser.
